# Python tests

Run from this directory:
```
uv run pytest -q
```

uv will install test dependencies declared in this folder's pyproject and run all tests.

Tests run against the in-tree SDK build: set `OVPHYSX_LIB` before invoking
pytest if you need to point at a non-default build output.

## Lockfile maintenance

`uv.lock` is generated by `uv` and should not be edited manually. It resolves
`ovstage` from the local `_build/target-deps/ovstage_wheel` staged by the ovphysx
build, so run the build first; then, if the lockfile is stale, regenerate it from
this directory:

```
uv lock
```

The pinned `ovstage` version in this lockfile is not authored here — it flows in
from the `OVSTAGE_VERSION` constant in `../../scripts/fetch_ovstage_release.py`
(via the `ovphysx` package's dependency). See "Updating the pinned ovstage version"
in [`../../AGENTS.md`](../../AGENTS.md); do not edit the ovstage pin in `uv.lock` by
hand.
